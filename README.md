# web-technologies
# аудит доступності
## опис

У роботі було перевірено сторінку `broken.html` через Lighthouse Accessibility audit. У початковому коді були проблеми з доступністю та семантикою HTML. Я знайшла ці проблеми, додала коментарі `A11Y`, виправила код і повторно запустила Lighthouse.

## які проблеми були

У сторінці не було `lang="uk"`, зображення були без `alt`, заголовки йшли у неправильному порядку, списки були зроблені через `<br>`, поле email не мало `label`, а `div` використовувався як кнопка. Також деякі посилання були без правильних атрибутів.

## чому це важливо

Доступність потрібна, щоб сайтом могли користуватися всі люди, зокрема ті, хто використовує скрінрідер або клавіатуру. Правильний HTML допомагає браузеру краще розуміти структуру сторінки.

## як виправлено

Я додала `lang="uk"`, `alt` для зображень, правильну структуру заголовків, списки `<ul><li>`, `label` для поля email, замінила `div onclick` на `<button>`, а для зовнішніх посилань додала `rel="noopener noreferrer"`.

## висновок

Після виправлень сторінка стала доступнішою, зрозумілішою для скрінрідерів і семантично правильнішою.
